Cara menerbitkan perubahan

GitHub Pages adalah hosting statis. Mengedit di browser tidak langsung mengubah website publik.

  1. Edit teks atau tabel dan simpan tiap perubahan.
  2. Klik Unduh revisi untuk mengunduh sop.js.
  3. Buka repository GitHub, ganti file data/sop.js dengan hasil unduhan.
  4. Klik Commit changes. Setelah proses GitHub Pages berhasil, situs publik menampilkan revisi terbaru.

Semua pengunjung dapat menggunakan editor lokal, tetapi hanya orang dengan izin repository dapat menerbitkan perubahan. Jangan memasukkan data rahasia ke situs publik.
