Cara menerbitkan perubahan ke GitHub

GitHub Pages tidak menyediakan penyimpanan langsung dari browser. Supaya perubahan terbaca oleh semua pengunjung:

  1. Pastikan revisi sudah disimpan pada editor.
  2. Klik Unduh hasil edit untuk mengambil file sop.js.
  3. Buka repository website di GitHub, lalu ganti file data/sop.js dengan file baru.
  4. Simpan perubahan dengan Commit changes. GitHub Pages akan menerbitkan versi terbaru.
Edit yang belum diterbitkan hanya tersimpan di perangkat/browser Anda. Jangan gunakan komputer umum untuk menyimpan draf rahasia.
